# Postly Privacy Policy Site

Static, Vercel-ready privacy-policy site for Postly's email-first LinkedIn writing assistant.

## Before deploying

Replace every instance of `privacy@YOUR-DOMAIN.com` in `index.html` with a real monitored privacy-contact email. Review the policy with a qualified lawyer if you need legal advice for your jurisdiction or business structure.

## Deploy on Vercel

Import the GitHub repository into Vercel and select the default static-site settings. Vercel will serve `index.html` with no build command required.
